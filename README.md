# LVhome — 梦蝶之后：一艘驶向自我的花船

Livy 的个人网站：一座漂在水上的多层花船博物馆。一层是她人生的一个阶段，一只蝴蝶带着访客从下往上走。方案来自 Livy 的策展案《梦蝶之后》和她的简历，文字都用她自己的口吻（“我”）。

纯静态，没有构建步骤。Three.js 和字体都放在 `assets/vendor/`，国内也能打开。

```sh
python3 -m http.server 8080   # 打开 http://localhost:8080
```

## 参观路线

1. **开场（船票）：** 夜里的水面，远处一艘花船。船票上写着：船名 Livy 号 · 航线 从记忆到成为 · 目的地 自我。下面可以选“谁来登船”（6 个人物 + 5 种肤色，和 lizhuojin.com 的人物一样）。
2. **坐船：** 乌篷船划到码头，前面有一只蝴蝶在飞，大约 15 秒，可以跳过。
3. **船里：** 和 Chris 的网站一样，斜上方俯视，前面两面墙切掉一半。点地板走路，方向键也能走，点物件会走过去并打开右侧面板（手机上是底部面板）。
4. **蝴蝶：** 每到一层，蝴蝶过一会儿从天井飞进来，停在一个地方。点它，它飞到楼梯上，楼梯一级一级亮起来，点楼梯就上楼。蝴蝶每层长得不一样：水墨剪纸 → 刺绣 → 玻璃 → 数字光点 → 发光。
5. **自由浏览：** 右边的楼层图可以直接去任意一层。“出船看看”可以绕船一圈，点任意一层进去。

## 深链接

- `?deck=3` 直接进第 4 层（编号从 0 开始，5 是船顶）。`?deck=3&panel=flight` 直接打开飞行舱。
- `?ride` 直接开始坐船；`?outside` 直接在船外。

## 部署

计划和 Chris 的网站一样：托管在 Cloudflare Workers 的静态资源上，连私有 GitHub 仓库 `rsm-zhl232/LVhome`，push 到 `main` 就会自动部署。

- `wrangler.jsonc`：部署配置。买好域名后加到 `routes` 里。
- `.assetsignore`：不公开的文件。
- `_headers`：缓存设置。
